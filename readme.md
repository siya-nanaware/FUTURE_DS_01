# Data Science & Analytics – Task 1 (2026)
## Business Sales Performance Analytics

### Overview
This project analyzes business sales data to identify revenue trends, top-performing products, and high-value regions. The analysis focuses on generating actionable insights that can help businesses improve performance and decision-making.

### Objectives
- Analyze revenue trends over time  
- Identify top-selling products  
- Identify high-revenue regions  
- Generate a business performance summary  

### Tools Used
- Python  
- Pandas  
- Matplotlib  

### Dataset
- Online Retail Dataset (Kaggle)  
- File: `online_retail.csv`

### Key Analysis
- Monthly revenue trends  
- Top 10 products by revenue  
- Top 10 countries by revenue  
- Overall business KPIs  

### How to Run
```bash
python sales_analysis.py
